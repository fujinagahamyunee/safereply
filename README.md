# SafeReply

의심 문자와 사용자가 선택한 행동을 바탕으로 위험 진행 단계를 **추정**하고 대응 방법 및 상담용 사고 요약을 제공하는 반응형 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열거나 저장소 루트에서 정적 HTTP 서버로 제공하면 됩니다. 앱은 별도 패키지 설치나 백엔드 없이 동작합니다.

## 분석 안내

- 위험 단계는 실제 피해·이체 시도, 앱 설치·정보 입력, 링크 클릭, 문자 수신 순으로 적용하는 규칙 기반 의사결정 트리 추정입니다. 학습된 AI 모델이나 스미싱 확정 판정이 아닙니다.
- 문자에서 찾은 URL 형식(축약 주소·IP·HTTP 등), 기관명, 민감정보·앱 설치·송금·긴급/보상 표현, 전화번호를 주변 문맥과 함께 보여주며 위험 단계 계산에는 반영하지 않습니다.
- 주소 방문이나 발신자 인증은 하지 않습니다. 키워드 규칙은 문맥을 완벽히 이해하지 못하므로 각 근거를 참고 단서로만 해석해야 합니다.
- 안내는 선택한 행동별로 달라지며 은행·경찰·금융감독원 등 공식 연락 경로를 이용하도록 안내합니다.
- 참고 데이터는 제공된 KR-MOB-SMISHING v1 합성 데이터 집계이며 실제 피해 통계가 아닙니다. 위험 단계 분류 학습에 사용하지 않았습니다.
- 입력 내용은 서버로 전송되거나 저장되지 않습니다.
