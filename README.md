# safereply

https://musical-space-fortnight-gx7qgxxvv9r726vx-4173.app.github.dev/
SafeReply는 스미싱 의심 문자를 받은 사용자가 자신의 피해 진행 상황을 파악하고 적절한 대응을 할 수 있도록 돕는 AI 기반 프로그램입니다. 사용자가 의심 문자 내용과 링크 클릭, 앱 설치, 개인정보 입력, 금융 이체 등의 행동 여부를 입력하면 이를 종합하여 위험 진행 단계를 4단계로 구분해 보여줍니다. 분석 결과에 따라 단계별 대응 방법을 제공하며, 문자 내용과 사용자 행동 이력, 위험 단계 등을 정리한 사고 요약 정보를 자동으로 생성하여 신고 및 상담에 활용할 수 있도록 합니다. 이를 통해 스미싱 피해가 의심되는 상황에서 사용자가 자신의 상황에 맞는 대응 방법을 신속하게 파악할 수 있도록 지원합니다.
